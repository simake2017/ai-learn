## 3. 怎么算相似度？（三种算法对比）

### 3.1 余弦相似度（最常用）

**数学公式**：

```
              a · b           a₁b₁ + a₂b₂ + ... + a₇₆₈b₇₆₈
cos_sim = ───────── = ─────────────────────────────────────────
            |a||b|        √(a₁²+a₂²+...+a₇₆₈²) × √(b₁²+...+b₇₆₈²)
```

**伪代码**：
```python
def cos_sim(a, b):
    dot = 0
    for i in range(768):
        dot += a[i] * b[i]      # 对应维相乘再求和
    
    norm_a = sqrt(sum(a[i]**2 for i in range(768)))
    norm_b = sqrt(sum(b[i]**2 for i in range(768)))
    
    return dot / (norm_a * norm_b + 1e-10)
```

**几何含义**：两向量夹角的余弦值
- 1.0：完全同向（向量一模一样）
- 0.0：正交（无关）
- -1.0：完全反向

### 3.2 欧氏距离（另一种方法）

```
dist(a, b) = √(Σ (aᵢ - bᵢ)²)
```

数值越小越相似（和余弦相反）。

### 3.3 点积（最简单）

```
a · b = Σ aᵢ × bᵢ
```

不考虑向量长度，只看方向。

## 8. 亲手算一遍

### 8.1 拿 2 维简化版算

假设 apple = [1, 0], pear = [0.8, 0.6]（简化 2 维）

```python
import math

apple = [1, 0]
pear = [0.8, 0.6]

# 1. 点积
dot = apple[0] * pear[0] + apple[1] * pear[1]
print(f"点积: 1*0.8 + 0*0.6 = {dot}")

# 2. 范数
norm_apple = math.sqrt(apple[0]**2 + apple[1]**2)
norm_pear = math.sqrt(pear[0]**2 + pear[1]**2)
print(f"|apple| = √(1² + 0²) = {norm_apple}")
print(f"|pear|  = √(0.8² + 0.6²) = {norm_pear}")

# 3. 余弦相似度
cos = dot / (norm_apple * norm_pear)
print(f"cos = {dot} / ({norm_apple} * {norm_pear}) = {cos:.4f}")
```

输出：
```
点积: 1*0.8 + 0*0.6 = 0.8
|apple| = 1.0
|pear|  = 1.0
cos = 0.8 / 1.0 = 0.8000
```

### 8.2 几何理解

```
apple = [1, 0]    ← 在 x 轴上
pear  = [0.8, 0.6] ← 在第一象限，靠近 x 轴

夹角 ≈ 37°，cos(37°) ≈ 0.8 → 0.8000 ✓

两个向量的"方向"很接近（夹角小），所以相似度高。
```

### 8.3 反例：apple vs car

```
apple = [1, 0]
car   = [0, 1]

dot = 0
cos = 0  ← 完全垂直，相似度为 0
```

## 9. 在 768 维中算真实值

### 9.1 完整算法（Python）

```python
import numpy as np

def cos_sim(a, b):
    """余弦相似度"""
    dot = np.dot(a, b)                # 点积（768 次乘 + 加）
    norm_a = np.linalg.norm(a)        # L2 范数（768 次乘方 + sqrt）
    norm_b = np.linalg.norm(b)
    return dot / (norm_a * norm_b + 1e-10)

# 真实例子
apple = np.array([0.1196, -0.1927, 0.2305, ...])  # 768 维
pear  = np.array([-0.0085, -0.1445, -0.0394, ...])

print(f"apple · pear = {np.dot(apple, pear):.4f}")
print(f"|apple|      = {np.linalg.norm(apple):.4f}")
print(f"|pear|       = {np.linalg.norm(pear):.4f}")
print(f"cos_sim      = {cos_sim(apple, pear):.4f}")
```

### 9.2 真实计算过程（apple ↔ pear）

假设取全部 768 维，**实际计算如下**（部分）：

```
点积 = 0.1196*(-0.0085) + (-0.1927)*(-0.1445) + 0.2305*(-0.0394) + ...
     = -0.00102 + 0.02785 + (-0.00908) + ...
     ≈ 数十次乘加 = 总值 A

|apple| = √(0.1196² + (-0.1927)² + 0.2305² + ...)
            = √(0.01431 + 0.03713 + 0.05313 + ...)
            ≈ √(总平方和) = 数值 B

|pear|  = √((-0.0085)² + (-0.1445)² + (-0.0394)² + ...)
            ≈ √(总平方和) = 数值 C

cos_sim = A / (B * C)
```

实际操作中，**我们不会手算**——直接用 NumPy：

```python
import numpy as np
wte = ...  # 加载
cos = np.dot(wte[apple_id], wte[pear_id]) / (
    np.linalg.norm(wte[apple_id]) * np.linalg.norm(wte[pear_id])
)
```

## 10. 为什么不同对比组相似度差这么多？

### 10.1 man ↔ woman = 0.59（高）

**共同维度（编码"人"）**：~700 维接近

**差异维度（编码"性别"）**：~50 维相反

### 10.2 apple ↔ pear = 0.30（低）

**共同维度（编码"水果"）**：~50 维接近

**差异维度（编码"具体哪个"）**：~700 维不同

### 10.3 apple ↔ car = 0.25（最低）

**共同维度**：几乎为 0（除了"都是普通名词"等）

**差异维度**：~760 维不同

### 10.4 直觉

```
man 和 woman 共享"人类"概念 → 共同特征多 → 高相似度

apple 和 pear 只是"都是水果" → 共同特征少 → 低相似度

apple 和 car 完全不同类 → 几乎没有共同特征 → 最低
```

## 11. 把这些写进一个交互式脚本

完整脚本：`python/vector_inspect.py`

```python
#!/usr/bin/env python3
"""
vector_inspect.py - 详细展示两个词的向量值和差别
"""
import numpy as np
import sys

# 加载
with open('/home/magene/runtime/ai/llm.c/gpt2_124M.bin', 'rb') as f:
    f.read(256*4)
    wte = np.frombuffer(f.read(50304*768*4), dtype=np.float32).reshape(50304, 768)

import tiktoken
enc = tiktoken.get_encoding("gpt2")

def vec(word):
    ids = enc.encode_ordinary(word)
    return wte[ids].mean(axis=0)

def cos_sim(a, b):
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-10))

def show(word1, word2, top=10):
    v1 = vec(word1)
    v2 = vec(word2)
    sim = cos_sim(v1, v2)
    d = v1 - v2
    abs_d = np.abs(d)
    
    print(f"\n{'='*60}")
    print(f"对比: '{word1}' vs '{word2}'")
    print(f"余弦相似度: {sim:.4f}")
    print(f"{'='*60}")
    
    # 最不同
    top_indices = np.argsort(abs_d)[-top:][::-1]
    print(f"\n最不同的 {top} 个维度:")
    print(f"{'维度':<6}{word1:>12}{word2:>12}{'差':>12}")
    for i in top_indices:
        print(f"{i:<6}{v1[i]:>12.4f}{v2[i]:>12.4f}{d[i]:>12.4f}")
    
    # 最相似
    bot_indices = np.argsort(abs_d)[:top]
    print(f"\n最相似的 {top} 个维度:")
    print(f"{'维度':<6}{word1:>12}{word2:>12}{'差':>12}")
    for i in bot_indices:
        print(f"{i:<6}{v1[i]:>12.4f}{v2[i]:>12.4f}{d[i]:>12.4f}")

# 交互
print("用法:")
print("  python vector_inspect.py apple pear")
print("  python vector_inspect.py man woman")
print()
if len(sys.argv) >= 3:
    show(sys.argv[1], sys.argv[2])
else:
    while True:
        try:
            w1 = input("\n词1> ").strip()
            w2 = input("词2> ").strip()
            if w1 and w2:
                show(w1, w2)
        except (EOFError, KeyboardInterrupt):
            break
```

### 用法

```bash
python3 python/vector_inspect.py apple pear
python3 python/vector_inspect.py man woman
python3 python/vector_inspect.py king queen
```

会显示：
- 余弦相似度
- 最不同的 10 个维度
- 最相似的 10 个维度

## 12. 关键洞察

1. **768 维向量**：每个词一个 768 个数字的数组
2. **余弦相似度**：算两向量"夹角"的余弦值（-1 到 1）
3. **差别在哪**：
 - 高相似度（0.5+）= 多数维度接近 +少量维度相反
 - 低相似度（<0.3）= 多数维度不同
4. **为什么有维度差**：模型训练时学到"性别/水果/王族"等独立概念，每个概念对应几个特定维度

**这就是"向量算术"和"语义相似"的本质**。
