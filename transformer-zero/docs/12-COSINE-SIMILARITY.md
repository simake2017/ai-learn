# 12 余弦相似度详解

> **从最基础开始**，用人话解释余弦相似度，包括公式、几何、对比、真实例子。

---

## 1. 一句话解释

**余弦相似度 = 两向量夹角的余弦值**，衡量**方向**有多接近。范围 [-1, 1]，越大越相似。

---

## 2. 类比：钟表指针

想象两支表针：

```
        12点
         ↑
         │
 9点 ←──┼──→ 3点
         │
         ↓
         6点

两指针的夹角:
 - 0°   → 完全重合（最相似）
 - 90°  → 垂直（无关）
 - 180° → 反向（最不相似）
```

**余弦相似度 = cos(夹角)**

---

## 3. 为什么用"余弦"？

### 3.1 数学性质

```
cos(0°)   = 1.0   (最相似)
cos(60°)  = 0.5
cos(90°)  = 0.0   (垂直)
cos(120°) = -0.5
cos(180°) = -1.0  (最不相似)
```

**优点**：
- 范围固定 [-1, 1]
- 越大越相似（直觉）
- 只看方向，不看长度

### 3.2 不受长度影响

```
a = [1, 0]   ← 短向量
b = [100, 0] ← 长向量（同方向）

欧氏距离: 大
余弦相似: 1.0  ← 同方向，高相似
```

词向量用余弦，因为：
- 我们关心**"词的含义"**（方向）
- 不关心**"词的重要性"**（长度）

---

## 4. 公式

### 4.1 数学公式

```
              a · b              a₁b₁ + a₂b₂ + ... + aₙbₙ
cos_sim = ───────────── = ─────────────────────────────────────────
            |a| × |b|       √(a₁²+...+aₙ²) × √(b₁²+...+bₙ²)
```

**分子** = 点积（点积=dot product，对应维相乘再求和）
**分母** = 两向量长度的乘积

### 4.2 完整公式拆解

```
点积:  a · b = Σᵢ aᵢ × bᵢ
        例:  [1,2,3] · [4,5,6] = 1×4 + 2×5 + 3×6 = 32

|a|:    向量长度 = √(Σᵢ aᵢ²)
        例:  |[1,2,3]| = √(1+4+9) = √14 ≈ 3.74

cos: =  32 / (3.74 × |b|)
```

---

## 5. 简化 2 维例子（手算）

### 5.1 完全同向

```
a = [3, 0]
b = [2, 0]

点积 = 3×2 + 0×0 = 6
|b| = √(2² + 0²) = 2
|a| = √(3² + 0²) = 3

cos = 6 / (3 × 2) = 1.0  ← 完全同向
```

### 5.2 垂直

```
a = [3, 0]
c = [0, 4]

点积 = 3×0 + 0×4 = 0
|a| = 3
|c| = √(16) = 4

cos = 0 / (3 × 4) = 0  ← 完全垂直，无关
```

### 5.3 反向

```
a = [3, 0]
d = [-3, 0]

点积 = 3×(-3) + 0×0 = -9
|a| = 3
|d| = 3

cos = -9 / (3 × 3) = -1.0  ← 完全反向
```

### 5.4 60 度夹角

```
a = [1, 0]
e = [0.5, 0.866]  (60° 方向)

点积 = 1×0.5 + 0×0.866 = 0.5
|a| = 1
|e| = 1

cos = 0.5 / 1 = 0.5  ← cos(60°) = 0.5 ✓
```

## 6. 在词向量中的实际计算

### 6.1 算 apple ↔ pear

```python
import numpy as np

apple = wte[apple_id]  # 768 维
pear  = wte[pear_id]

# 点积：每维相乘再求和
dot = 0
for i in range(768):
    dot += apple[i] * pear[i]

# 范数：平方和开方
norm_apple = sqrt(sum(apple[i]**2 for i in range(768)))
norm_pear  = sqrt(sum(pear[i]**2  for i in range(768)))

# 余弦相似度
cos = dot / (norm_apple * norm_pear)
```

实际跑出来是 **0.2956**。

### 6.2 实际值

```python
# NumPy 一行搞定
cos = np.dot(apple, pear) / (np.linalg.norm(apple) * np.linalg.norm(pear))
# → 0.2956
```

## 7. 几何意义

### 7.1 把768 维画成高维空间

每个词是空间中的一个**点**（或向量，从原点出发）。

```
              · apple
            ╱
          ╱  ← 夹角 = θ
        ╱
      · pear

cos(θ) = 相似度
```

### 7.2 余弦相似度与夹角

```
夹角 θ    cos(θ)    含义
0°        1.00      完全重合
 30°       0.87      很接近
 60°       0.50      还行
 90°       0.00      无关
 120°      -0.50     偏离
 180°      -1.00     反向
```

### 7.3 类比"语义空间"

把高维空间想象成一个**语义地图**：
- 同类词聚集在一起（向量方向接近）
- 不同类词分散在不同方向
- 距离 = 语义差异

```
        · 苹果
       ╱│
      ╱ │
     ╱  │
    ·   · 梨
   香蕉

   都接近 → 都是水果
```

## 8. 对比：余弦 vs 欧氏距离 vs 点积

| | 余弦相似度 | 欧氏距离 | 点积 |
|---|---|---|---|
| 范围 | [-1, 1] | [0, ∞) | (-∞, +∞) |
| 越大越 | 相似 | 不相似 | 不一定 |
| 受长度影响 | 否 | 是 | 是 |
| 用法 | 词向量、推荐 | 坐标、几何 | 简单比较 |

### 8.1 例子对比

```
a = [1, 0]    b = [100, 0]    c = [0, 1]

余弦:
 cos(a,b) = 1.0   (同方向)
 cos(a,c) = 0.0   (无关)

欧氏距离:
 dist(a,b) = 99   (远)
 dist(a,c) = √2  (中等)

点积:
 a·b = 100
 a·c = 0
```

**结论**：
- 余弦只看方向（a 和 b 同方向 → 相似）
- 欧氏距离看实际距离（a 和 b 距离远）

## 10. 代码实现（Python）

### 10.1 基础版

```python
import math

def cos_sim(a, b):
    """余弦相似度（手写）"""
    # 1. 点积
    dot = sum(a[i] * b[i] for i in range(len(a)))
    
    # 2. 范数
    norm_a = math.sqrt(sum(a[i]**2 for i in range(len(a))))
    norm_b = math.sqrt(sum(b[i]**2 for i in range(len(b))))
    
    # 3. 余弦
    return dot / (norm_a * norm_b + 1e-10)
```

### 10.2 NumPy 版（推荐）

```python
import numpy as np

def cos_sim(a, b):
    """余弦相似度（NumPy）"""
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-10))
```

### 10.3 批量计算

```python
def top_k_similar(target_vec, vocab_vecs, vocab_words, k=10):
    """找 top-k 最相似的词"""
    similarities = []
    for word, vec in zip(vocab_words, vocab_vecs):
        sim = cos_sim(target_vec, vec)
        similarities.append((word, sim))
    similarities.sort(key=lambda x: -x[1])
    return similarities[:k]
```

## 11. 常见误解

### 11.1 余弦相似度 = 距离吗？

**不是**！

- 余弦相似度：[-1, 1]，越大越相似
- 欧氏距离：[0, ∞)，越小越相似

可以转换：`distance = 1 - cos_sim`，但要小心 [0, 2] 范围。

### 11.2 余弦相似度 0 = 完全无关吗？

不完全是！0 = "完全垂直"，但实际数据中很少完全垂直。大多数词之间至少有一些共享维度。

### 11.3 余弦相似度 1 = 完全相同吗？

对！cos=1 表示两向量完全同向。
