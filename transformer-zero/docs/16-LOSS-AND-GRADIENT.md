# 16 损失函数与梯度：从误差到反向传播

> 从 `c/attention.c` 里一个不起眼的除法出发，把 **损失函数 L、梯度 ∂L/∂θ、链式法则、交叉熵** 这四件事一次性讲透。

## 0. 引子：`attention.c:24` 那个除法在干什么

```c
// c/attention.c:22-24
int C3 = C * 3;          // Q/K/V 拼起来
int hs = C / NH;         // 每个 head 维度 = d_k
float scale = 1.0f / sqrtf((float)hs);
```

这行对应论文 *Attention Is All You Need* §3.2.1 的缩放项：

```
Attention(Q, K, V) = softmax( Q·K^T / sqrt(d_k) ) · V
```

**为什么必须除 `sqrt(d_k)` 而不是 `d_k`？** 答案藏在"方差 → softmax 饱和 → 梯度消失"这条链上，见 §8 通路 B。

本文档按这条链一路走下来：

```
attention 的一个除法
   → 方差为什么重要
   → 梯度到底是什么
   → 误差怎么变成梯度
   → 链式法则怎么把梯度传回去
   → 损失函数怎么设计
```

## 1. 梯度的本质：敏感度 + 方向

```
∂L/∂某个量 = 这个量每变化 1 单位，L 变化多少
```

每个梯度值同时携带两件事：

| 部分 | 含义 | 读法 |
|---|---|---|
| **绝对值** | 影响力多大 | "我动它一下，损失晃多少" |
| **正负号** | 往哪边动能降损失 | 损失曲线在你脚下那段的**斜率** |

**符号不是"负的意思"，而是"损失随这个量上升而下降"。**

### 1.1 符号自洽表

以本文档后面那个贯穿始终的小例子为例（`x=[3.0,1.0]`, `W=[0.5,-0.2]`, `b=0.1`, `y=2.0`）：

| 量 | 值 | 读法 |
|---|---|---|
| `e = y - ŷ` | **+0.6** | 预测**欠**了 0.6 |
| `∂L/∂ŷ` | **-0.6** | ŷ 越大损失越小 |
| `∂L/∂b` | **-0.6** | b 涨 0.1 → ŷ 涨 0.1 → L 降 0.06 |
| `∂L/∂W₁` | **-1.8** | W₁ 涨 0.1 → ŷ 涨 0.3 → L 降 0.18 |
| `∂L/∂W₂` | **-0.6** | W₂ 涨 0.1 → ŷ 涨 0.1 → L 降 0.06 |

### 1.2 两个负号是不同的事

| 位置 | 是什么 | 谁规定的 |
|---|---|---|
| `∂L/∂ŷ = ŷ - y = -0.6` | **曲线的斜率**，损失函数本身决定 | 数学定义 |
| `W ← W - lr * ∂L/∂W` | **更新规则**，规定要往反梯度方向走 | 优化的选择 |

合起来：

```
梯度是负的 (-0.6)  →  说明往上加能降损失
更新时减去梯度      →  W += lr * 0.6   实际是"往上加"
结果方向正确 ✓
```

**所以"负梯度"不等于"往负方向走"。** 梯度告诉你损失往哪边升，更新规则负责往反方向走。

### 1.3 通用规则

```
梯度 > 0  →  这个参数往小的方向调，损失会降
梯度 < 0  →  这个参数往大的方向调，损失会降
梯度 ≈ 0  →  往哪调都无所谓
             ├─ 已经最优（真收敛）
             └─ 前面挂着 x_j = 0，根本没信号（这个权重白占参数）
```

最后一种情况值得警惕：**不是"已经学好了"，是"永远学不到"**。这正是 ReLU 死亡神经元、缺失特征、恒零偏置会毁掉训练的原因。

## 2. L 是什么：损失函数

**L = Loss，损失函数**，也叫目标函数 / 代价函数。

| 性质 | 说明 |
|---|---|
| 它是**一个函数** | 输入 = (预测 ŷ, 真值 y)，输出 = **一个数** |
| 这个数衡量 | "这次预测有多差" |
| 训练的全部目的 | **把这个数降到最小** |

### 2.1 本项目里 L 具体是什么

```c
// c/activations.c:63-74  逐 token 的交叉熵
void crossentropy_forward(float* losses, const float* probs,
                          const int* targets, int B, int T, int V) {
    for (int b = 0; b < B; b++) {
        for (int t = 0; t < T; t++) {
            const float* probs_bt = probs + b * T * V + t * V;
            int target = targets[b * T + t];
            float p = probs_bt[target];
            if (p < 1e-30f) p = 1e-30f;      // 防 log(0) = -inf
            losses[b * T + t] = -logf(p);
        }
    }
}

// c/model.c:284-285  求平均 → 这就是 L
model->mean_loss = total / (B * T);

// c/model.c:287  没有 target 时的哨兵值
model->mean_loss = -1.0f;
```

所以 **`L` = `model.mean_loss`**，就是你训练时屏幕上滚动的那行 `loss = 3.4000`。

### 2.2 碗的比喻

```
        L (损失) = 碗壁高度
                   ▲
                   │
              ╲    │    ╱
               ╲   │   ╱
     ŷ 你在这儿  ●──┴──●  y 真值在碗底（L=0）
                ╱      ╲
               ╱        ╲
```

- `ŷ` = 你在碗壁上的位置
- `L` = 你所在位置的**高度**
- **梯度 = 碗壁在你脚下有多陡**（绝对值）+ **往哪边是上坡**（符号）
- 训练 = 一步步往碗底走

**梯度下降 = 沿着最陡的下坡方向下山。** 这就是全部。

## 3. 完整手算：三个梯度从哪来

这一节用**一个贯穿全文的小例子**，把 `∂L/∂ŷ`、`∂L/∂b`、`∂L/∂W` 三个数一格一格算出来。

### 3.1 前向

```text
x = [3.0, 1.0]          # 2 个输入特征
W = [0.5, -0.2]         # 1 个输出单元，2 个权重
b = 0.1

ŷ = 0.5*3.0 + (-0.2)*1.0 + 0.1 = 1.5 - 0.2 + 0.1 = 1.4
y = 2.0
e = y - ŷ = 0.6          # 预测偏小，欠了 0.6
L = 1/2 * (2.0 - 1.4)² = 1/2 * 0.36 = 0.18
```

### 3.2 一个公式套三个参数

```text
∂L/∂θ  =  (∂L/∂ŷ) · (∂ŷ/∂θ)  =  (ŷ - y) · (∂ŷ/∂θ)  =  -e · (∂ŷ/∂θ)
                  ↑                       ↑
          已经算过 = -0.6          换一个参数就要重算
```

`∂ŷ/∂θ` 的含义：**参数 θ 动 1 单位，预测 ŷ 会跟着动多少**（一个"换算率"）。

| θ | `∂ŷ/∂θ` | 来源 | `∂L/∂θ = -0.6 × 它` |
|---|---|---|---|
| `ŷ` | 1 | ŷ 就是 ŷ | `-0.6 × 1 = -0.6` |
| `b` | **1** | b 直接加在 ŷ 上 | `-0.6 × 1 = -0.6` |
| `W₁` | **x₁ = 3.0** | W₁ 前面挂 x₁ | `-0.6 × 3.0 = -1.8` |
| `W₂` | **x₂ = 1.0** | W₂ 前面挂 x₂ | `-0.6 × 1.0 = -0.6` |

### 3.3 ① `∂L/∂ŷ = -0.6`：展开 L

L 里只有 ŷ 是变量（y 是常数）：

```text
L = 1/2 (y - ŷ)²
  = 1/2 (y² - 2yŷ + ŷ²)          ← 展开平方

逐项对 ŷ 求导：
  ∂/∂ŷ [ 1/2 y² ]  = 0        ← y 是常数，导数为 0
  ∂/∂ŷ [ -yŷ   ]  = -y
  ∂/∂ŷ [ 1/2 ŷ² ] = ŷ

  ∂L/∂ŷ = ŷ - y = 1.4 - 2.0 = -0.6
```

也可以用损失表直接读出斜率（`L = 1/2(2.0-ŷ)²`）：

| ŷ | L | |
|---|---|---|
| 1.39 | 0.18505 | |
| **1.40** | **0.18** | ← 我们在这 |
| 1.41 | 0.17405 | |

```text
(L(1.41) - L(1.40)) / 0.01 = (0.17405 - 0.18) / 0.01 = -0.595 ≈ -0.6
```

> 用 0.1 的大步长算会得到 -0.55 而不是 -0.6 —— 那是因为抛物线有曲率。**导数是局部斜率**，要用足够小的步长去逼近。

### 3.4 ② `∂L/∂b = -0.6`：把 b 换成变量

**把 b 单独拎出来当自变量**，其他全部代成数字：

```text
ŷ = 0.5×3.0 + (-0.2)×1.0 + b = 1.3 + b

L(b) = 1/2 (2.0 - (1.3 + b))²
     = 1/2 (0.7 - b)²

∂L/∂b = 1/2 × 2(0.7 - b) × (-1) = -(0.7 - b)

代入 b = 0.1：
  ∂L/∂b = -(0.7 - 0.1) = -0.6 ✓
```

**关键**：这里的系数是 **1**，因为 b 前面没有别的东西挡着。

### 3.5 ③ `∂L/∂W₁ = -1.8`：把 W₁ 换成变量

```text
ŷ = W₁×3.0 + (-0.2)×1.0 + b = 3W₁ - 0.2 + b

L(W₁) = 1/2 (2.0 - (3W₁ - 0.2 + b))²
       = 1/2 (2.2 - 3W₁ - b)²

∂L/∂W₁ = 1/2 × 2(2.2 - 3W₁ - b) × (-3)
        = -3 × (2.2 - 3W₁ - b)

代入 W₁ = 0.5, b = 0.1：
  括号里 = 2.2 - 1.5 - 0.1 = 0.6
  ∂L/∂W₁ = -3 × 0.6 = -1.8 ✓
```

**关键**：这里的系数是 **3**，正是 `x₁ = 3.0`。

### 3.6 ④ `∂L/∂W₂ = -0.6`：同一个套路

```text
ŷ = 0.5×3.0 + W₂×1.0 + b = 1.5 + W₂ + b

L(W₂) = 1/2 (2.0 - (1.5 + W₂ + b))²
       = 1/2 (0.5 - W₂ - b)²

∂L/∂W₂ = -(0.5 - W₂ - b)

代入 W₂ = -0.2, b = 0.1：
  括号里 = 0.5 + 0.2 - 0.1 = 0.6
  ∂L/∂W₂ = -0.6 ✓
```

### 3.7 三次计算并排看：规律一目了然

```text
L(b)   = 1/2 (0.7  - b      )²     括号里的 0.7 就是"离真值还差多少"
L(W₁)  = 1/2 (2.2  - 3W₁ - b )²   3 来自 x₁ = 3.0
L(W₂)  = 1/2 (0.5  - W₂ - b )²   1 来自 x₂ = 1.0
```

**每一次求导，都是"括号里的残差"乘上一个"敏感度系数"：**

| | 残差（= y - ŷ） | 敏感度系数 | 乘积 |
|---|---|---|---|
| `∂L/∂b` | 0.6 | **1**（b 直连） | **-0.6** |
| `∂L/∂W₁` | 0.6 | **3.0**（= x₁） | **-1.8** |
| `∂L/∂W₂` | 0.6 | **1.0**（= x₂） | **-0.6** |

**残差都一样是 0.6**（因为只有 ŷ 一个预测值），**差异全部来自敏感度系数**，而系数**就是输入向量 x 的对应分量**。

### 3.8 推广到矩阵形式

多输出、多输入时同理：

```text
∂L/∂b = ŷ - y                              (m×1)
∂L/∂W = (ŷ - y) xᵀ                        (m×n)
```

外积 `(ŷ-y) xᵀ` 的第 (k, j) 个元素就是 `(ŷ_k - y_k) × x_j` —— 正是"第 k 个输出的残差 × 第 j 维输入"。

**写成代码：**

```c
// 对每个参数元素：∂L/∂W[k][j] = (ŷ[k] - y[k]) * x[j]
for (int k = 0; k < m; k++) {
    float err = out[k] - target[k];        // 残差（带符号）
    for (int j = 0; j < n; j++) {
        grad[k * n + j] = err * inp[j];    // 外积的一行
    }
}
```

### 3.9 验证：更新后预测确实变好了

```text
梯度下降 (lr = 0.1)，W ← W - lr*∂L/∂W：
  W₁ ← 0.5   - 0.1*(-1.8) = 0.68
  W₂ ← -0.2  - 0.1*(-0.6) = -0.14
  b   ← 0.1   - 0.1*(-0.6) = 0.16
```

**验证**：新预测 `ŷ = 0.68*3 + (-0.14)*1 + 0.16 = 2.04 - 0.14 + 0.16 = 2.06`，从 1.4 逼近 2.0 ✓（lr 没调小所以略微过冲，正常）。

## 4. 为什么写成 `∂L/∂ŷ`？分母不是除法

### 4.1 求导必须回答"对谁求导"

`L` 不是孤零零的数，它是**一个多元函数**：

```text
L( ŷ, y, W, b, x, ... )
```

单独写 `∂L` 是**不完整的**，就像问"这栋楼多高？"—— 多高取决于从哪个方向量。

**分母 `∂ŷ` 就是那个"方向"。**

### 4.2 这不是除法

```text
∂L/∂ŷ
```

读作 **"L 关于 ŷ 的偏导数"**（partial derivative of L **with respect to** ŷ），是一个整体的记号，**不表示 `∂L` 除以 `∂ŷ`**。

| 记号 | 读法 | 实际含义 |
|---|---|---|
| `∂L/∂ŷ` | L 关于 ŷ 的偏导 | 一个数 |
| `∂L/∂W` | L 关于 W 的偏导 | 一个矩阵（形状同 W） |
| `dL` | L 的全微分 | 所有变量一起动时的变化率 |

`∂` 这个符号本身就是"**偏**导数"的标记 —— 意思是"**固定住其他所有变量，只让这一个动**"。

### 4.3 L 到底是谁的函数：依赖图

```text
              ┌──────────┐
   x ────────▶│  ŷ = Wx+b│◀──── W, b
              └────┬─────┘
                   │
                   ▼
              ┌──────────┐
   y ────────▶│    L     │◀──── y
              └──────────┘
```

所以对同一个 L，有四种合法的求导问法：

| 问法 | 公式 | 意义 | 我们要吗 |
|---|---|---|---|
| L 关于 ŷ | `∂L/∂ŷ` | 预测动一下，损失动多少 | **要**（中间量） |
| L 关于 W | `∂L/∂W` | 权重动一下，损失动多少 | **要**（最终目标） |
| L 关于 b | `∂L/∂b` | 偏置动一下，损失动多少 | **要**（最终目标） |
| L 关于 y | `∂L/∂y` | 真值动一下，损失动多少 | ❌ **不要** |

**为什么 y 不求导？** `y` 是**给定的真值标签**，是常量。梯度下降更新的是 W 和 b，不是 ŷ，更不是 y。你可以算 `∂L/∂y`，但算它毫无意义 —— **你不会去"修改答案"来降低损失**，那属于作弊。

### 4.4 梯度必须和参数同形状

| 求导对象 | L 的类型 | 导数的类型 | 例子 |
|---|---|---|---|
| `ŷ`（标量） | 标量 | **标量**（一个数） | `∂L/∂ŷ = -0.6` |
| `W`（矩阵 m×n） | 标量 | **矩阵 m×n** | `∂L/∂W = (ŷ-y)xᵀ` |

**关键：梯度的形状必须和被求导的参数一模一样。** 因为矩阵的每个元素 `W_ij` 都要有一个自己的"敏感度"，否则你不知道该往哪个格子、往哪边、调多少。**梯度就是一张"每个参数该往哪调"的地图。**

## 5. "直接对 L 求导"其实真的可以

`∂L/∂W_ij` 最原始的定义（不借助任何链式法则）：

```text
∂L/∂W_ij = lim(Δ→0)  [ L(W + Δ·E_ij, ...) - L(W, ...) ] / Δ
```

翻译成大白话：

> **只把 `W_ij` 这一个格子推一点点，看 L 动了多少，除以推动的量。**

**这正是本项目 `c/autodiff.c` 的实现** —— 每个参数元素各来一次：

```c
// c/autodiff.c:24-35
model->params_memory[i] = saved + eps;   // 只推第 i 个参数
gpt_forward(model, inputs, targets);
float L_plus = model->mean_loss;         // L(θ + ε)

model->params_memory[i] = saved - eps;   // 反方向再推一次
gpt_forward(model, inputs, targets);
float L_minus = model->mean_loss;        // L(θ - ε)

model->grads_memory[i] = (L_plus - L_minus) / (2.0f * eps);
```

**这就是字面意义上的"直接对 L 求导"。** 没有任何链式法则，没有中间量。

### 5.1 两种算法的分工

| | 做法 | 每个参数的代价 | 用途 |
|---|---|---|---|
| **数值微分**（本项目） | 中心差分 | **2 次完整前向** | 教学 + 校验 |
| **反向传播**（链式法则） | 解析求导 | 1 次前向 + 1 次反向 | 工业标配 |

假设参数量 10M：

```text
数值差分：  10M × 2 = 2000 万次完整前向   ← 训练一次要跑几个月
反向传播：  1 次前向 + 1 次反向            ← 几小时
```

**差了上千万倍。**

## 6. 链式法则：连乘，不是套娃

### 6.1 最常见的误解

```text
❌ 套娃： ∂/∂W [ ∂L/∂ŷ ]
```

**这不成立，而且一眼就能看出为什么不成立：**

```text
∂L/∂ŷ = -0.6   ← 这是一个【数】，不是函数
```

**数没法再求导。** 所以只能是：

```text
✅ 相乘：
   ∂L/∂W = ( ∂L/∂ŷ ) × ( ∂ŷ/∂W )
            └──数──┘    └──矩阵──┘
              数 × 矩阵 = 矩阵 ✓  形状还对上了
```

**链式法则告诉你"影响要连乘"，不是"导数要套娃"。**

### 6.2 分清谁是外层、谁是内层

```text
L = f(ŷ)          ← 外层 f：输入是"预测值"，输出是"损失"
ŷ = g(W)          ← 内层 g：输入是"权重"，输出是"预测值"

复合起来：  L(W) = f( g(W) )
```

代入数字：

```text
f(u) = 1/2 (y - u)²        u 是 ŷ
  f'(u) = -(y - u) = u - y
  代入 u = ŷ = 1.4：  f'(1.4) = 1.4 - 2.0 = -0.6

g(W) = Wx + b               x=[3.0,1.0], b=0.1
  g'(W) = x = [3.0, 1.0]

链式法则：相乘
  dL/dW = f'(g(W)) · g'(W)
        = (-0.6) × [3.0, 1.0]
        = [-1.8, -0.6]     ✓ 和 §3 算的完全一致
```

### 6.3 "先外后内"作为遍历顺序是对的，但漏了"相乘"

| | 说法 | 对不对 |
|---|---|---|
| **作为公式** | 链式法则是"先外后内再相乘" | ❌ 是**乘法**，且外层导数必须**代入内层的输出值**才可用 |
| **作为反向遍历顺序** | 从 L 一路往里走到 W | ✅ **完全正确**，这就是"反向传播"的定义 |

**真正的计算顺序：**

```text
① 前向：算出中间值
   W=0.5, b=0.1, x=[3.0,1.0]
   → ŷ = 1.4                                    ← 关键：先把这个数备好

② 反向：从外往里，一层一层取导数
   外层：f'(u) = u - y，代入 u=1.4 → -0.6        ← 靠 ① 才能算
   内层：g'(W) = x = [3.0, 1.0]

③ 相乘
   (-0.6) × [3.0, 1.0] = [-1.8, -0.6]
```

**为什么外层导数"必须先有内层的输出值"？**

`f'(u) = u - y` 是个**函数**，不是数。`f'(g(W))` 要代入 `g(W)` 的具体值才算得出数。

> **前向传播 ↔ 反向传播 必须成对存在。反向传播要用前向传播留下的中间值。**

### 6.4 齿轮类比

```text
曲柄 ──[齿轮比 A]──▶ 中间轴 ──[齿轮比 B]──▶ 输出轴
```

曲柄转 1 圈，输出轴转多少？

```text
总传动比 = B × A      ← 相乘，不是套娃
```

反过来，从输出轴往回推每个零件该转多少：

```text
输出轴转 1 圈 → 中间轴转 1/B → 曲柄转 1/(B·A)
```

**这正是反向传播：**

| 齿轮 | Transformer 里的对应物 |
|---|---|
| 曲柄 | 权重 W（要更新的） |
| 齿轮比 | 局部导数（∂ŷ/∂W 之类） |
| 输出轴 | 损失 L（误差信号从这里发出） |
| 传动比连乘 | 链式法则连乘 |

**误差信号从 L 出发，沿着传动链一节一节往回传，每节乘上该节的传动比。**

### 6.5 多层 = 连乘

```text
u = Wx + b        = 1.4
v = 2u            = 2.8
L = 1/2 (v - 4)²

∂L/∂v = v - 4 = -1.2
∂v/∂u = 2
∂u/∂W = x = [3.0, 1.0]

∂L/∂W = (-1.2) × 2 × [3.0, 1.0]
       = -2.4 × [3.0, 1.0]
       = [-7.2, -2.4]
```

**三层就是三个导数连乘。每多一层，梯度就多一个因子** —— **这也是深层网络梯度消失/爆炸的根源**（因子连乘几十层就会趋于 0 或无穷）。

### 6.6 为什么链式法则能快这么多

```text
∂L/∂W = (∂L/∂ŷ) × (∂ŷ/∂W)
        └──┬──┘   └───┬──┘
      一次算，全参数共享   每个参数只要一个数
```

关键在于 **`(∂L/∂ŷ)` 只算一次，就能喂给下面所有参数**。在 `ŷ = Wx + b` 这一层：

```text
∂ŷ/∂W = xᵀ       ← 和 W 无关！所有参数共享同一个 xᵀ
∂ŷ/∂b = 1        ← 更简单
```

再往下一层是 attention、softmax、layernorm……每层都是同样的模式：**局部导数算一次，往上传的时候被上游的信号乘一下**。

## 7. 损失函数通常怎么定义

### 7.1 通用骨架

```text
L = (1/N) * Σ_i  ℓ( ŷ_i , y_i )
        └──聚合──┘  └─单样本惩罚─┘
```

三层可以独立设计：

| 层 | 决定什么 | 常见选择 |
|---|---|---|
| `ℓ(ŷ, y)` | **单个样本错的时候罚多少** | 平方 / 绝对值 / -log p |
| 聚合方式 | **怎么把一堆样本的惩罚汇成一个数** | 求和 / 平均 / 加权平均 |
| 是否取平均 | **决定梯度的绝对量级** | 见 §7.5 |

### 7.2 按"错得多严重"分家族

| 损失 | ℓ(ŷ, y) | 任务 | 梯度特点 |
|---|---|---|---|
| **平方损失 (MSE)** | `(ŷ - y)²` | 回归 | `2(ŷ-y)`，错得越离谱梯度越大 |
| **绝对损失 (L1/MAE)** | `|ŷ - y|` | 回归、抗离群 | `sign(ŷ-y)`，**不随误差大小变化** |
| **Huber** | 小误差用平方、大误差用绝对 | 回归兼顾 | 可导 + 抗离群 |
| **交叉熵 (CE)** | `-Σ_v q_v log p_v` | 分类 | `p - q`，**永远在 [-1,1]** |
| **负对数似然 (NLL)** | `-log p_y` | 分类/语言模型 | CE 在 one-hot 标签下的特例 |

**读法**：前三个衡量"数值差多远"（几何距离），后两个衡量"概率错多少"（信息论代价）。

### 7.3 为什么语言模型用交叉熵（推导一遍）

**第 1 步：从"最大似然"出发**

训练的目标是让模型给正确 token 的概率 `p_y` 尽可能大。概率乘积取对数变求和：

```text
L = -log p_y
```

**第 2 步：展开成 logits 的形式**

`p` 是 softmax 的输出：

```text
p_v = e^{z_v} / Σ_j e^{z_j}

L = -log(e^{z_y} / Σ_j e^{z_j})
  = -z_y + log(Σ_j e^{z_j})
```

**第 3 步：求导（这一步会给出漂亮的结果）**

```text
∂L/∂z_v = -δ_{vy} + e^{z_v} / Σ_j e^{z_j}
         = -δ_{vy} + p_v
```

one-hot 标签下 `δ_{vy} = q_v`，所以：

```text
∂L/∂z_v = p_v - q_v
```

**"预测概率 减去 真实分布"** —— 这个形式极其干净，含义一目了然：预测偏高就往下压，偏低就往上抬。

### 7.4 交叉熵为什么"对"（三个理由）

**理由 1：和最大似然是同一件事，不是拍脑袋设计的。** 交叉熵是"信息论损失"，但它同时就是**负对数似然**，天然对应"让正确预测的概率最大"。

**理由 2：梯度量级天然有界。**

| 损失 | 梯度能长多大 |
|---|---|
| MSE | `2(ŷ-y)`，误差 1000 时梯度就是 2000 → **容易炸** |
| 交叉熵 | `p - q`，**永远在 [-1, 1]** → 天然稳定 |

这直接呼应 §1：**交叉熵把"误差多大"编码成了概率差，而不是原始差值**，所以梯度不会失控。

**理由 3：数值上可以稳定计算。**

`log Σ e^{z_j}` 如果 z 很大，`e^{z_j}` 会溢出。工程上用 **log-sum-exp 技巧**：

```text
log Σ e^{z_j} = max_z + log Σ e^{z_j} - max_z
                       └────── 提出来，指数里就都是 ≤ 0 的数 ──────┘
```

**这个技巧在本项目里出现两次**：

```c
// c/activations.c:42-48  softmax
float maxval = logits_bt[0];                    // 找出最大值
for (int v = 1; v < V; v++)
    if (logits_bt[v] > maxval) maxval = logits_bt[v];
for (int v = 0; v < V; v++) {
    float e = expf(logits_bt[v] - maxval);      // 减掉 max，指数不会溢出
```

```c
// c/attention.c:39-52  attention 里的 softmax
float maxval = -1e30f;
for (int t2 = 0; t2 <= t; t2++) {
    ...
    if (val > maxval) maxval = val;
}
```

**全项目所有 softmax 都必须这么写**，否则大 logits 直接 `inf` → `nan`。

### 7.5 本项目的完整形态

```text
输入：logits (B, T, V)              每个位置对整个词表的打分
   │
   ├─ softmax_forward   →  probs (B,T,V)     每个位置是一个概率分布
   │
   ├─ crossentropy_forward → losses (B,T)    每位置: -log p[正确 token]
   │     activations.c:72   losses[b*T+t] = -logf(p);
   │                      p = probs[b,t,target]
   │
   └─ 求平均 → L = model.mean_loss          model.c:285
         total / (B*T)
```

| 设计点 | 说明 |
|---|---|
| **逐 token 求 -log p** | 每个位置独立算一次损失（causal LM 的标准做法） |
| **对 B*T 平均** | 整个 batch 所有位置拉平，得到一个标量 `L` |
| **`p < 1e-30f` 兜底** | 防止 `log(0) = -inf` 导致 loss 变 nan |
| **`mean_loss = -1.0f` 兜底** | `model.c:287`，没有任何 target 时用哨兵值 |

**这个 `L` 就是 `autodiff.c` 里被扰动后重算的那个数** —— 前后呼应：

```c
model->params_memory[i] = saved + eps;
gpt_forward(model, inputs, targets);
float L_plus = model->mean_loss;    // ← 就是这个 L
```

### 7.6 判据：怎么判断一个损失函数好不好

| # | 判据 | 含义 | 反例 |
|---|---|---|---|
| 1 | **最小值点正确** | `ŷ = y` 时 L 最小 | 任何"距离型"损失都满足 |
| 2 | **可导（或次梯度够用）** | 否则梯度下降跑不动 | 阶跃函数类损失 |
| 3 | **尺度合理** | 梯度不能太大（炸）或太小（消失） | MSE 用在分类上，梯度小到学不动 |
| 4 | **对离群点鲁棒**（视任务） | 一个坏样本不能毁掉整个 batch | MSE 遇到离群点会被拖着走 |
| 5 | **与真实目标一致** | 代理指标 ≠ 目标就白干 | 训练 loss 降了但生成质量没变 |

### 7.7 五个常见陷阱

| 陷阱 | 后果 | 解法 |
|---|---|---|
| **求和不平均** | 梯度随 batch size 线性放大，学习率得跟着改 | 除以 N |
| **尺度不匹配学习率** | loss 量级变了，lr 没跟着调 → 炸或不学 | loss 换算时同步缩放 lr |
| **忘记 epsilon** | `log(0)` → nan，之后全 nan | `p < 1e-30f` 兜底（本项目已做） |
| **softmax 不减 max** | `exp(大数)` 溢出 → inf/nan | 减 max（本项目已做） |
| **分类用 MSE** | 梯度小、概率不归一、收敛慢 | 分类一律交叉熵 |

## 8. 方差与梯度的三条通路

初学者常把"方差"和"梯度"混为一谈。精确地拆开：

| 说法 | 判定 | 精确说法 |
|---|---|---|
| 误差 = 真值 - 预测值 | ✅ 对 | `e = y - ŷ` |
| 误差是梯度的直接因子 | ✅ 对 | `∂L/∂ŷ = ŷ - y = -e` |
| 预测值的关键参数是方差 | ⚠️ 跳步了 | 预测值 `ŷ = f_θ(x)`，**参数是权重 θ**；方差是分布的二阶矩 |
| 方差是梯度的重要参数 | ✅ 方向对，机制要说清 | 方差影响梯度的**分配**、**饱和**、**噪声底** |

### 通路 A：特征方差 → 梯度在参数间的分配 → 有效学习率

由 `∂L/∂W_kj = -e_k * x_j` 可见：某维输入 `x_j` 的方差越大，`W_ij` 收到的梯度就越大，**这一维就以更快的有效学习率在更新**。

> **方差决定的是梯度怎么分，不是梯度的符号。**

这正是 BatchNorm / LayerNorm 存在的理由 —— 把各维方差拉平，让每个参数拿到**公平的学习率**。

### 通路 B：score 方差 → softmax 饱和 → 梯度消失（§0 的那个除法）

softmax 的雅可比：

```text
∂p_j/∂s_i = p_i * (δ_ij - p_j)
```

它的量级上界是 `p(1-p)`，最大 0.25。但当 `p` 饱和到接近 1 时，`p(1-p) → 0`，**梯度直接被掐死**。

而 `p` 会不会饱和，取决于 score 的标准差。设初始化下 `Var(q) = Var(k) = 1`：

```text
Var(Q·K^T) = d_k * Var(q) * Var(k) = d_k
```

`hs = 64` 时 score 的标准差是 8，score 分布 ≈ `N(0, 8²)`，取值轻松到 ±24：

| | score 标准差 | softmax 行为 | 梯度 |
|---|---|---|---|
| 不缩放 | 8 | 近乎 one-hot 硬 argmax | ≈ 0（消失） |
| 除 `sqrt(64)` | 1 | 柔和，p 分布合理 | 健康 |

**这就是"方差影响梯度"最硬的一条证据**，也是 `c/attention.c:24` 那个 `scale` 存在的全部理由。

完整链条：

```
hs 太大 → Var(Q·K^T) ∝ hs 变大 → score 标准差变大
       → softmax 饱和 → ∂p/∂s = p(1-p) → 0
       → 梯度消失 → 模型学不动

scale = 1/sqrt(hs) → score 方差归一 → p 分布健康 → 梯度能流动
```

> **实践推论**：把 `hs` 从 64 改成 512 而忘了同步改缩放（或反过来），注意力会**静默地**从"能训练"退化成"训不动"，loss 曲线看起来只是收敛慢一点，很容易被误判成超参问题。**缩放因子和 head 维度必须联动改。**

### 通路 C：梯度自身的方差 → SGD 的噪声球底噪

SGD 的稳态误差满足：

```text
E||g||² = ||E[g]||² + Tr(Σ)
```

`Tr(Σ)` 就是**梯度噪声的方差**。它不改变梯度的均值方向，但决定了 SGD 在最优点附近**能晃到多大半径**：

- 梯度方差大 → 噪声球大 → 最终 loss 地板高，收敛精度差
- 梯度方差小 → 噪声球小 → 能逼近更深的谷底

Adam 的 `v` 项（二阶矩）就是显式地在追踪这个量：

```c
// c/optimizer.c:45
float adam_update = m_hat / (sqrtf(v_hat) + opt->eps);
```

**"梯度的方差"是优化器里的一等公民。**

### 一句话校准

> **误差决定梯度的大小；特征方差决定梯度的分配；score 方差决定梯度的生死；梯度方差决定训练的终局精度。**
> 它们是四件不同的事，都跟方差有关，但不能揉成"方差是梯度的参数"。更准确地说：**方差是"分布"的属性，梯度是"偏导"的属性；两者通过雅可比和链式法则相互影响，而不是谁是谁的参数。**

### 9.1 本项目为什么用数值微分

// c/main.c:78-87

float loss = model.mean_loss;

## 12. 一句话总结

```
L 是损失函数 —— 一个数，用来衡量预测有多差
  本项目里 L = model.mean_loss（平均交叉熵）

∂L/∂某个量 是在求导数，但它的本质不是符号演算，
  而是"把那个量推一点点，看损失动了多少"
  —— 也就是梯度下降每一步赖以决策的"坡度"

∂L/∂ŷ = ŷ - y = -0.6        残差（带符号）
∂L/∂b = -0.6                残差 × 1（b 直连）
∂L/∂W = [-1.8, -0.6]        残差 × 输入向量 x（外积）

链式法则是【连乘】不是【套娃】——
  因为 ∂L/∂ŷ 求出来是个【数】，数没法再求导

"直接对 L 求导"不是不行，是太慢：
  数值微分 = 每个参数 2 次前向（本项目现状）
  链式法则 = 1 次前向 + 1 次反向（工业标准）

损失函数的选择 = 梯度形状的选择
  交叉熵赢在：目标对齐 + 梯度有界 + 数值可算
```
