# Roadmap：从"能转的发动机"到"能跑的车"

> 本项目已完成：微型 GPT 的**全部核心数学链路**（Embedding → Attention → MLP → 交叉熵 → 数值微分 → AdamW → 自回归生成）。
> 以下按"先补原理、再上规模"排序，带 ⭐ 的是性价比最高的下一步。

## Phase 1：补全"核心拼图"（仍是教学范围）

| 优先级 | 事项 | 说明 | 对应缺口 |
|---|---|---|---|
| ⭐⭐⭐ | **解析反向传播** | 用链式法则手写 backward，替换数值微分 | 现在每步 ~5 分钟，补上后秒级，是解锁一切规模实验的前提 |
| ⭐⭐⭐ | **BPE 分词器** | 从字符级升级到子词级，理解 vocab 从 65 → 5万 的过程 | 所有真实 LLM 的入口 |
| ⭐⭐ | **采样策略** | temperature、top-k、top-p | 现在推理是贪心/随机裸采样，控制不了输出多样性 |
| ⭐⭐ | **KV Cache** | 推理时缓存历史 K/V，每步 O(T) 变 O(1) | 长文本生成加速几个数量级，工程必备 |

## Phase 2：真实训练体验（小规模可行）

| 优先级 | 事项 | 说明 | 对应缺口 |
|---|---|---|---|
| ⭐⭐⭐ | **中文语料训练** | 用宋词/现代文几 MB 语料，字符级 vocab ~4000 | 验证"这套东西真的能学会语言"，英文 Shakespeare 不直观 |
| ⭐⭐ | **PyTorch 对拍** | 写一个结构相同的迷你 GPT，两边对 forward 数值 | 对上了才叫真懂，也是最强的单测 |
| ⭐⭐ | **loss 曲线 + attention 可视化** | 复用 python/visualize.py，观察训练动态 | 训练不收敛时能"看见"问题 |
| ⭐ | **学习率调度 + 梯度裁剪** | cosine decay、grad clip | 真实训练不炸的标配 |

## Phase 3：理解"现代改良"（读论文预热）

> 这些都**不是新原理**，而是你眼前代码的"换装版"。每项建议只做最小改动 + 对照实验。

| 优先级 | 事项 | 一句话本质 |
|---|---|---|
| ⭐⭐ | **RoPE 旋转位置编码** | 把"wpe 查表加向量"换成"对 Q/K 做旋转" |
| ⭐⭐ | **GQA / MQA** | 多个 Q 共享一份 K/V，省显存 |
| ⭐ | **SwiGLU 激活** | GELU 换成门控版，MLP 变胖一点 |
| ⭐ | **RMSNorm** | LayerNorm 去掉均值中心化，少一步 |

## Phase 4：明确不做（避免范围蔓延）

| 不做 | 原因 |
|---|---|
| 分布式训练 / 混合精度 | 属于工程，不属于原理，看 llm.c |
| Encoder / Cross-Attention（BERT、T5 路线） | 本项目定位 GPT（decoder-only） |
| 追 SOTA 架构（MoE、Mamba 等） | 先把经典吃透，新架构都是变体 |
| 生产部署 | 用 HuggingFace + vLLM |

## 建议的下一步

**从 Phase 1 的"解析反向传播"开始** —— 它是性价比最高的一项：
没有它，任何上规模的实验（Phase 2/3）都会被"每步 5 分钟"卡死；
有了它，整个项目从"教学演示"升级为"可以真玩的实验平台"。
