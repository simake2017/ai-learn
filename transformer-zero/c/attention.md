# attention.c 核心自注意力机制推论详解

> 本文档针对 `c/attention.c` 中的因果自注意力（Causal Self-Attention）实现进行逐行原理解析，通过具体数值例子还原前向推论全过程。

---

## 1. 为什么需要注意力机制？

以包含 4 个 Token 的简单短句为例：

```text
位置 0: "小狗"
位置 1: "跑累了"
位置 2: "它"
位置 3: "睡着了"
```

在刚进入 Attention 层之前，每个词仅经过静态查表（`wte + wpe`）：
- `"小狗"` 拥有犬类动物的特征向量；
- `"它"` 仅具有通用第三人称单数代词特征，自身**完全不知道具体指代什么**；
- 模型必须在运行到 `"它"`（`t = 2`）时，借助注意力机制回头检索上文，将 `"小狗"` 的语义注入到 `"它"` 的向量中。

---

## 2. 算子参数与维度设定

对应函数定义：`attention_forward(out, preatt, att, inp, B, T, C, NH)`

| 参数名 | 物理意义 | 本例取值 | 解释 |
|---|---|---|---|
| `B` | 句子批次大小 | `1` | 处理 1 句话 |
| `T` | 序列长度 | `4` | 句子共有 4 个词 |
| `C` | 特征总通道数 | `2` | 跟踪 2 个特征（特征 0：动物属性；特征 1：动作属性） |
| `NH` | 注意力头数 | `1` | 设为单头便于手算跟踪 |
| `hs` | 单头维度 | `2` | `hs = C / NH = 2 / 1 = 2` |

---

## 3. 完整前向推论过程（以 t = 2 即 "它" 为例）

### 3.1 第一步：QKV 提取（代码第 31、42、79 行）

输入数组 `inp` 包含由前序 MatMul 投影好的所有 Q、K、V 向量（形状 `B × T × 3C`）：

| 位置 `t` | 词语 | Query (Q: 需求) | Key (K: 标签) | Value (V: 携带内容) |
|---|---|---|---|---|
| `0` | `"小狗"` | `[0.0, 0.0]` | `[3.0, 0.0]`（动物属性极强） | `[10.0, 1.0]`（携带浓厚的犬类实体语义） |
| `1` | `"跑累了"` | `[0.0, 0.0]` | `[0.0, 3.0]`（动作属性极强） | `[1.0, 8.0]`（携带疲惫动作语义） |
| `2` | `"它"` | `[3.0, 0.0]`（急需寻找动物实体） | `[0.1, 0.1]` | `[0.0, 0.0]`（自身无具体实体内容） |
| `3` | `"睡着了"` | `[0.0, 0.0]` | `[0.0, 2.0]` | `[0.0, 5.0]` |

- 当前词 `"它"` 发出的查询 `Q = [3.0, 0.0]`，代表它正在整个句子中寻找**具有动物特征（特征 0）的主体**。

---

### 3.2 第二步：原始打分点积（代码第 37~50 行）

计算公式：`preatt[t2] = (Q[2] · K[t2]) / sqrt(hs)`，其中缩放因子 `scale = 1 / sqrt(2) ≈ 0.7071`：

- **对 `"小狗"` (`t2=0`)**：
  `点积 = 3.0 * 3.0 + 0.0 * 0.0 = 9.0`
  `打分 = 9.0 * 0.7071 ≈ 6.36`（强匹配！）
- **对 `"跑累了"` (`t2=1`)**：
  `点积 = 3.0 * 0.0 + 0.0 * 3.0 = 0.0`
  `打分 = 0.0 * 0.7071 = 0.00`
- **对自身 `"它"` (`t2=2`)**：
  `点积 = 3.0 * 0.1 + 0.0 * 0.1 = 0.3`
  `打分 = 0.3 * 0.7071 ≈ 0.21`
- **对 `"睡着了"` (`t2=3`)**：
  属于未来位置，被后续因果掩码遮蔽。

---

### 3.3 第三步：因果掩码与 Softmax 归一化（代码第 55~73 行）

由于自回归模型不能偷看未来，约束必须满足 `t2 <= t`（即只能看 `t2 = 0, 1, 2`）：

```text
exp(6.36) ≈ 578.25   ("小狗")
exp(0.00) = 1.00     ("跑累了")
exp(0.21) ≈ 1.23     ("它")

求和 sum = 578.25 + 1.00 + 1.23 = 580.48
```

归一化后存入 `att_bth[t2]`：
- `att[0]`（对 `"小狗"`）：`578.25 / 580.48 ≈ 0.996`（**99.6%**）
- `att[1]`（对 `"跑累了"`）：`1.00 / 580.48 ≈ 0.002`（**0.2%**）
- `att[2]`（对自身）：`1.23 / 580.48 ≈ 0.002`（**0.2%**）
- `att[3]`（对未来词）：`0.000`（**0.0%**，强制置零）

---

### 3.4 第四步：加权求和更新内容（代码第 76~84 行）

核心关键代码：

```c
for (int i = 0; i < hs; i++) {
    float o = 0.0f;
    for (int t2 = 0; t2 <= t; t2++) {
        const float* value_t2 = inp + b * T * C3 + t2 * C3 + h * hs + 2 * C;
        o += att_bth[t2] * value_t2[i]; // 第 80 行
    }
    out[b * T * C + t * C + h * hs + i] = o;
}
```

实质运算展开：

#### 1. 计算特征 0（动物实体属性）：
```text
o[0] = att[0] * V_小狗[0]  +  att[1] * V_跑累了[0]  +  att[2] * V_它[0]
     = 0.996 * 10.0       +  0.002 * 1.0          +  0.002 * 0.0
     = 9.96 + 0.002 + 0.0
     ≈ 9.96
```

#### 2. 计算特征 1（动作属性）：
```text
o[1] = att[0] * V_小狗[1]  +  att[1] * V_跑累了[1]  +  att[2] * V_它[1]
     = 0.996 * 1.0        +  0.002 * 8.0          +  0.002 * 0.0
     = 0.996 + 0.016 + 0.0
     ≈ 1.01
```

## 4. 结论：计算前后的本质变化

| 阶段 | `"它"` 的特征向量 | 语义状态 |
|---|---|---|
| **计算前（仅查表）** | `[0.0, 0.0]` | 空壳代词，无具体实体属性 |
| **计算后（加权融合后）** | **`[9.96, 1.01]`** | **成功吸收了 `"小狗"` 的实体语义，具备完整的犬类属性** |

至此，通过第 80 行的加权求和，词语与上文上下文完全打通融合，模型后续能够准确预测出后续的动作或描述。
