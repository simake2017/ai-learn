# test_05_attention：两个词的对话 —— 因果自注意力完整推演

> 本文是 `test/test_05_attention.c` 的配套解释，**所有数字与测试用例一一对应**。
> 测试原文：[test_05_attention.c](test_05_attention.c)

## 1. 场景设定：一句话只有两个词

想象模型正在读一句超短的话：

```text
位置 0: "小猫"     ← 一只具体的动物
位置 1: "它"       ← 一个空壳代词，还不知道指谁
```

进入 Attention 层之前，每个词只经历了"查表"（Embedding），所以：

- `"小猫"` 带着猫的特征；
- `"它"` 只是一个通用代词，**自己完全不知道指代的是猫还是狗还是桌子**。

注意力的任务，就是让 `"它"` 回头看 `"小猫"`，把对方的语义借一点过来。

本用例为了手算方便，把规模压到最小：**B=1, T=2, C=4, NH=2**（2 个 head，每个 head 看 2 维），缩放系数 scale = 1/√2 ≈ 0.7071。

## 2. 输入数据（与测试第 59~68 行完全一致）

每个 token 携带 Q/K/V 三组向量，各 4 维（两个 head 各占前 2 维 / 后 2 维）：

| 位置 | 词 | Q (查询) | K (标签) | V (携带的内容) |
|---|---|---|---|---|
| Token 0 | `"小猫"` | [1, 0, 1, 0] | [1, 0, 1, 0] | **[10, 20, 30, 40]** |
| Token 1 | `"它"`   | [0, 1, 0, 1] | [0, 1, 0, 1] | **[50, 60, 70, 80]** |

head0 只看前 2 维，head1 只看后 2 维，而前后两段的数字完全相同，
所以**算懂 head0 就等于算懂了全部**（head1 结果对称，见第 6 节）。

给向量一个"人话"解释（head0 的 2 个维度）：

- **维度 0 = 动物属性强度**
- **维度 1 = 独立事物属性强度**（代词、物品这类"不依赖上下文"的东西）

于是：

- `"小猫"` 的标签 K = [1, 0]：**"我是动物，不是游离事物"**
- `"它"` 的标签 K = [0, 1]：**"我是个待填充的代词槽位"**
- `"它"` 的查询 Q = [0, 1]：**"我想找同类事物 / 我关心的是事物维度的匹配"**

## 3. 逐步推演（head0）

### Step 1：打分 —— Q · K / √d

`"它"`（位置 1）拿自己的 Q=[0, 1] 去和每个词的 K 做点积：

| 看谁 | 点积 [0,1]·K | × 0.7071 | 得分 |
|---|---|---|---|
| 看 `"小猫"` K=[1,0] | 0×1 + 1×0 = 0 | × 0.7071 | 0 |
| 看自己 `"它"` K=[0,1] | 0×0 + 1×1 = 1 | × 0.7071 | 0.7071 |

注意这个打分结果的"人情味"：**"它"找"同类事物"时，跟自己完美匹配，跟"小猫"完全正交**（动物 ≠ 事物槽位）。

### Step 2：因果掩码 —— 不许偷看未来

`"小猫"`（位置 0）在位置 1 之前，它**只能看自己**：

```text
score[0][0] = [1,0]·[1,0] × 0.7071 = 0.7071
score[0][1] = -∞  （因果掩码：未来位置直接屏蔽）
att[0] = softmax([0.7071, -∞]) = [1.0, 0.0]
```

这就是因果掩码的意义：训练时整段话一次喂进去，位置 t 的答案绝不允许
偷看 t 之后的词，否则就是在"抄答案"。

### Step 3：softmax —— 分数变概率

对 `"它"` 的得分 [0, 0.7071] 做 softmax：

```text
e^0     = 1.000
e^0.7071 ≈ 2.028
求和 = 1 + 2.028 = 3.028

att[1] = [1/3.028, 2.028/3.028] = [0.3303, 0.6697]
```

含义非常直白：**"它" 67% 保留自己，33% 借鉴 "小猫"**。

### Step 4：加权求和 V —— 真正"借语义"的一步

head0 中 V[小猫] = [10, 20]，V[它] = [50, 60]：

```text
out[1]_h0[0] = 0.3303 × 10 + 0.6697 × 50 = 3.303 + 33.485 = 36.788
out[1]_h0[1] = 0.3303 × 20 + 0.6697 × 60 = 6.606 + 40.182 = 46.788
```

而 `"小猫"`（位置 0）因为只能看自己，输出原封不动就是自己的 V：

```text
out[0]_h0 = 1.0 × [10, 20] = [10, 20]
```

## 4. 结果验证（对照测试断言）

| 断言（测试行号） | 期望值 | 含义 |
|---|---|---|
| `out[0]` = 10.0 (L116) | 10.0 | `"小猫"` 输出 = 自己的 V |
| `out[1]` = 20.0 (L117) | 20.0 | 同上 |
| `out[4]` ≈ 36.788 (L142) | 36.788 | `"它"` 借词后维度 0 |
| `out[5]` ≈ 46.788 (L143) | 46.788 | `"它"` 借词后维度 1 |
| `att[0→0]` = 1.0 (L157) | 1.0 | 位置 0 只看自己 |
| `att[0→1]` = 0.0 (L158) | 0.0 | **因果掩码生效**，看不到未来 |

## 5. 这个故事说明了什么

对比 `"它"` 借词前后的向量（head0 视角）：

| 阶段 | "它" 的向量 | 状态 |
|---|---|---|
| 注意力计算前 | 只知道自己是"代词" | 空壳 |
| 注意力计算后 | [36.788, 46.788]，混入了 33% 的"小猫"内容 | 开始带上小猫的语义色彩 |

因为本例里 `"它"` 的查询和 `"小猫"` 的标签正交（匹配度 0），只借了 33%。
如果 `"它"` 的 Q 设计成急切找动物（如 Q=[1, 0]），那打分就会变成
[0.7071, 0]，softmax 后变成 [0.6697, 0.3303]——**超过一半的成分来自"小猫"**，
指代就基本锁定了。`c/attention.md` 里的"小狗/它"例子正是这种强匹配版本。

## 6. head1 在哪？

head1 使用维度 2、3，输入为：

```text
Q/K: [1,0] / [0,1]（与 head0 相同）
V:   [30, 40] / [70, 80]  （恰好是 head0 的 V + 20）
```

计算过程与 head0 一模一样，结果：

```text
out[0]_h1 = [30, 40]
out[1]_h1 = [0.3303×30 + 0.6697×70, 0.3303×40 + 0.6697×80]
          = [56.788, 66.788]
```

所以完整输出（测试里的 out[0..7]）：

```text
out = [10, 20, 30, 40,  36.788, 46.788, 56.788, 66.788]
       └── t=0 ──┘        └─────── t=1 ────────┘
```

两个 head 用同一套匹配规则、各自处理不同维度的 V——这就是"多头"的全部本质：
**同一句话，多个视角同时各看各的**。

## 7. 一图流总结

```text
"它" 想问: 我是谁? 我该携带什么内容?
        │
        ▼ Q=[0,1]
   ┌────打分 Q·K/√2────┐
   │  对"小猫": 0       │  ← 正交，不太相关
   │  对自己:   0.7071  │  ← 完美匹配
   └──────┬─────────────┘
          ▼ softmax + 因果掩码(挡住未来)
   att = [0.3303, 0.6697]   "33% 借小猫, 67% 留自己"
          ▼
   out = 0.3303×[10,20] + 0.6697×[50,60]
       = [36.788, 46.788]   ← "它" 的输出有了具体内涵
```
